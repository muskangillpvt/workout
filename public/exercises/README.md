# Exercise images

Drop photos or illustrations here using these exact filenames and the app
will pick them up automatically. Nothing needs to be added for the app to
work — any exercise without an image here will show a soft placeholder
instead, so the UI never breaks.

Recommended: square-ish images, at least 400×400px, JPG or PNG.

Filenames used by the app:

- squats.jpg
- incline-pushup.jpg
- rows.jpg
- wall-angels.jpg
- glute-bridge.jpg
- dead-bug.jpg
- bird-dog.jpg
- plank.jpg
- side-plank.jpg
- reverse-lunge.jpg
- reverse-fly.jpg
- walking.jpg
- chest-stretch.jpg
- arm-circles.jpg
- shoulder-rolls.jpg
- good-morning.jpg
- hip-circles.jpg

To change or add images, edit `src/data/exercises.js` — each exercise has an
`image` field pointing to `/exercises/<filename>`.
